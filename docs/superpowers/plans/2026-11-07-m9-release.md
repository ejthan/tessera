# M9 Release 1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tessera ready for the maintainer to release: i18n enforced, accessibility checked, the last spec gaps closed, a locally built macOS package, written workflows, a docs site and a QA checklist. Nothing is published.

**Architecture:** `xtask` gains `i18n`, `governance`, `dco`, `icons`, `dist` and `release-notes`. `tessera-core` gains `ui_thread` and `RequestLog::latest_failed`. `tessera-app` gains contrast overrides, budget spans, a last-failure control, a breadcrumb, a search field, several windows and a local connect path on the welcome screen. Packaging config lives in `crates/tessera-app/Cargo.toml`. Three local slices: A (Tasks 1 to 3), B (Tasks 4 to 8), C (Tasks 9 to 13).

**Tech Stack:** Rust 1.99.1, GPUI Kit 0.9.0 (gpui-pre 0.3.11), rust-i18n 4.2.4. External tools, not in `Cargo.toml`: cargo-packager 0.11.8, cargo-generate-rpm 0.21.1, mdbook 0.5.4.

**Spec:** [`docs/superpowers/specs/2026-11-07-m9-release-design.md`](../specs/2026-11-07-m9-release-design.md). Section numbers below (§7.1 …) refer to it unless they say "product spec". Read the section a task names before starting it.

## Global Constraints

- **Nothing is published.** No task pushes, tags, creates a release or a PR, uploads anything, or creates labels on GitHub. `gh` is used read-only or not at all. Commits only if the controller says so; the dispatch for this design said do not commit, and each implementer's dispatch decides for its task.
- **No secret is read.** No task, script or workflow reads `APPLE_*` or any signing credential. Ad-hoc signing uses the identity `-`.
- **No claim beyond evidence.** A result seen only on screen, in a screen reader, on Linux or Windows, or in a workflow run goes into `docs/qa-checklist.md` as a maintainer step. Say "not run" for a workflow. GUI screenshots do not work here.
- **Docker may be down.** M9 needs no new endpoint and no live test. Do not restart Docker or OrbStack. **Never send anything to port 8108**; a test may hold the string `localhost:8108` in a form, and must open no socket.
- Every source file starts with `// SPDX-License-Identifier: GPL-3.0-or-later`.
- `tessera-client` and `tessera-core` never depend on GPUI. Direction: `app → widgets → core → client`.
- Direct dependencies are pinned exactly in the workspace `Cargo.toml`. The one new crate is `png = "=0.18.1"`, for `xtask` only, in Task 9. Adding any other crate needs a stop and a report.
- Never guess a GPUI or GPUI Kit API. Read the pinned source under `~/.cargo/registry/src/*/gpui-component-0.9.0`, `gpui-base-0.9.0`, `gpui-kit-0.9.0` and `gpui-pre-0.3.11` first. When a task names a file there, it was verified; anything else, verify the same way.
- `cargo-packager` facts in the design marked **packager** were read from docs.rs and from the `main` branch. Check them on the installed 0.11.8. A difference goes into the task's report and into the design, not around it.
- Every UI string goes through `t!()`, same keys in `assets/locales/en.yml` and `de.yml` (flat keys), and `cargo xtask i18n` stays green once Task 1 lands.
- No blocking I/O on the GPUI thread.
- No key in logs, files, errors, `Debug` or `Display`. Redaction tests are never removed.
- After every task: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test --workspace`. No commit with a failing check.
- Commits: `git commit -s`, message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- UX rules: environment visible everywhere; errors inline and in full; default focus never on a destructive action; no dead controls; every action keyboard-reachable with its shortcut shown on the control via `Kbd::binding_for_action` or `Kbd::global_binding_for_action`.
- Shortcuts follow the `#[cfg(target_os = "macos")]` constant pairs in `crates/tessera-app/src/actions.rs`. `alt-cmd-n` and `alt-cmd-r` and their `ctrl-alt-` twins are free today.
- NF5: the release binary stays below 41,943,040 bytes.
- English in the repository, except `assets/locales/de.yml`.
- Each task ends with its CHANGELOG entry under `## [Unreleased]` → `### Added`, in user terms.

## Review Focus

1. No path in any task or workflow publishes, or reads a credential. `release.yml` uses `GITHUB_TOKEN` only, and the plan never runs it.
2. A second window must not open tabs the first asked for, and a connection must never show in two windows. Test in Task 7.
3. Closing the last window quits on every platform, and quit hooks still flush. Test in Task 7.
4. `assert_off` must not fire in release, and must not fire in a test harness. Task 4.
5. The lint must fail on a real hardcoded string, and `// i18n-ok` must need a reason. Task 1.
6. Contrast overrides must survive a system appearance change, and must not touch `theme.font_size`. Task 3.
7. The local connect path fills a form and opens no connection. Task 8.
8. Each row of the design's "what is real" table stays honest: nothing not built is called built, in the CHANGELOG, the book or the checklist. Task 13.
