# Security policy

Tessera handles Typesense API keys, including admin keys. Please report security problems privately.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue.

We aim to answer within 7 days and will keep you updated until the issue is resolved.

## Scope

In scope: anything that could leak an API key (logs, config files, crash output, the request log), bypass the read-only mode, or send requests to hosts the user did not configure.
