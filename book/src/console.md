# Raw console

⇧⌘Y / Ctrl+Shift+Y or Console in the sidebar opens a tab per connection for any request.

The path completes from the API and your collections. ⇧⌘A / Ctrl+Shift+A adds a query row, and the body is JSON, text, or a file of up to 64 MiB (⌘O / Ctrl+O, ⌥⌘O / Ctrl+Alt+O removes it).

⌘↩ / Ctrl+Enter sends. Tessera refuses a path that could leave the node, a parameter that holds a key and a masked body, and says why. A write unlocks a read-only connection first. A dangerous request asks, by typing the name for a deleted collection and on prod.

## The answer

Body is ⌘3 / Ctrl+3 and headers are ⌘4 / Ctrl+4. Secrets show masked until ⌥⌘K / Ctrl+Alt+K. A warning shows when a 200 hides failed import lines or searches. The console keeps at most 32 MiB of an answer and says when it cut one, and ⌥⌘[ and ⌥⌘] / Ctrl+Alt+[ and Ctrl+Alt+] page through a long one.

## More

A write goes on when the tab closes.
