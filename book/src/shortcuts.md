## Your own shortcuts

`keymap.toml` in the config folder adds to the defaults or replaces them. The folder is listed in [Settings](settings.md) under Storage, and the file is read once at start.

```toml
[[binding]]
key = "cmd-shift-p"
action = "tessera::OpenPalette"

[[binding]]
key = "cmd-k"        # no action: the chord does nothing
context = "Workbench"
```

- `key` is one chord, or several separated by spaces, with the modifiers `cmd`, `ctrl`, `alt`, `shift`.
- `action` is an action name such as `tessera::Refresh`. Leave it out to unbind the chord.
- `context` limits the binding to a view, such as `Workbench`, `Console` or `Documents`.
- A binding without `cmd`, `ctrl` or `alt` also fires while you type in a field, so bind a chord.

A bad entry is skipped and named above the tabs, and the others apply. A file that does not parse changes nothing, and the same line names the place. `escape` cannot be bound, so a dialog can always be left. An action you unbind stays reachable from its control and the palette.
