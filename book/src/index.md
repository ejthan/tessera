# Tessera

Tessera is a fast, native desktop client for Typesense. It covers the admin API of a server or cluster: collections, documents, search, synonyms, curation, keys and operations, with safeguards for production clusters. It runs on macOS, Windows and Linux and needs no browser and no server component.

Tessera is not affiliated with or endorsed by Typesense, Inc. "Typesense" is a trademark of Typesense, Inc.

## What you get

- Saved connections with their keys in your system's credential store.
- An environment tag on each connection, and a red band and frame on prod.
- A document table that scrolls through large collections and loads pages as you go.
- Imports and exports that run as jobs, with progress, stop and a report per line.
- A request log with every request Tessera sends, secrets masked.
- A keyboard shortcut for each action, shown on its control.

Tessera is built for Typesense 30 and is tested on 30.0 and 30.2. It sends no telemetry.

## Finding your way

Start with [Install](install.md) and [Getting started](getting-started.md). The chapters after that follow the sidebar. Press ⌘K / Ctrl+K in the app to find any action by name.

Shortcuts are written for both keyboards: ⌘K / Ctrl+K means ⌘K on macOS and Ctrl+K on Windows and Linux.
