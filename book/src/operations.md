# Operations

The Ops row (⌥⌘0 / Ctrl+Alt+0) runs an operation on the node you pick there. Each result shows under its row with the node and the time.

| Operation | Shortcut |
|---|---|
| Snapshot | ⌘1 / Ctrl+1 |
| Compact | ⌘2 / Ctrl+2 |
| Clear cache | ⌘3 / Ctrl+3 |
| Leader vote | ⌘4 / Ctrl+4 |
| Runtime config | ⌘S / Ctrl+S |

Snapshot and vote need the name typed on prod. A read-only connection unlocks first. A bad path or value says why and sends nothing.

The tab reads each node's role every 2 seconds while it shows, and lists the running schema changes.
